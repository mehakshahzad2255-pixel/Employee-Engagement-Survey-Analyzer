# Employee Engagement Survey Analyzer

An Oracle APEX-based application for employee engagement survey management, data collection, and analysis.

## Project Overview

The Employee Engagement Survey Analyzer helps organizations manage employee survey responses and analyze engagement-related data through an interactive web application.

## Technologies Used

- Oracle APEX
- Oracle Database
- SQL
- HTML, CSS and JavaScript

## Project Structure

```text
Employee-Engagement-Survey-Analyzer/
├── f97150/
│   └── Oracle APEX application export
├── database/
│   └── EE_SURVEY_DB_DDL.sql
├── .gitignore
└── README.md
```

## Database

The `database` folder contains the SQL Data Definition Language (DDL) script used to define the database schema.

## Application Setup

1. Log in to Oracle APEX.
2. Import the application SQL export.
3. Configure the required database objects.
4. Run the application.
